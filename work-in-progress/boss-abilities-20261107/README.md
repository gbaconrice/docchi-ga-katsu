## 実装範囲

既存IDに49能力を実装。現在大型扱いの46種と、ブルーシェルジャイアント・リングウォーデン・リッチスクライブの3種です。価格、ID、選択順、素材は維持しています。能力を従来の攻撃へ無条件に積み増さず、新しい攻撃周期・範囲・威力・発動条件へ置き換えました。旧一律3倍ダメージは新能力の個別係数へ置き換えています。

- 炎・氷・雷・毒・地形の持続効果、独立した多頭攻撃、貫通光線。
- 掴み投げ、突進と後退、凍結と氷片、拘束、連続する柱、密集地への隕石。
- 成長、反射、味方の防御、死亡時爆発、二段分裂、瓦礫の壁、敵死体からの骸骨。
- 次のフレームからの状態適用、行動阻害への耐性時間、対象数・召喚数・持続時間の上限。
- 能力別の予告とエフェクト、氷像、打ち上げ、幽体化、成長、味方の強化表示。描画データはリプレイへ記録します。

比較カードの「基準威力」は能力の威力計算の基準で、全段・全対象の合計ではありません。個別の段数、継続、対象数などは実装定義にあります。

## 検証済みと未完了

- 専用167チェックに合格。
- 実際の戦闘エンジンによる66チェックに合格。49種ごとの反復再現、左右反転、対象不在、死亡時の中断、描画付き実行との一致、リプレイ往復を含みます。
- 分裂は二世代・子孫12体まで、リッチの新しい蘇生は3体まで。死亡時の連鎖、投げの巻き込み、盾の破壊も実際のダメージで確認しています。
- 既存一般兵の比較戦闘は旧版と数値一致。573画像のバイト一致、公開形式から元ソースへの完全復元を確認。
- 初回の旧173試験は150合格。旧能力を前提とした試験、固定されたハッシュ等が含まれます。そこで見つかった4つの表示・ログの不具合は修正し、最新ソースで全試験を再実行中です。旧173試験全合格という意味ではありません。
- ブラウザーでの実際の見た目、実機スマートフォン、実GRAVITY SDK、実ネットワーク対戦は未確認。
- 2,208条件の遠距離比較と別の混成軍比較を実施中。勝率校正済みではなく、強さの最終調整は未完了です。

QA画面では相手の体力や攻撃停止を設定した専用の配置を使います。通常対戦の勝率確認には使えません。SDK、財布、ランキングへ送信しません。
