# Tavern and sound preview

This separate preview is based on the root game at commit `73ccd6c`. It adds candidate home art, larger prediction text, a shorter character preview box, and sample sound effects. The root and GRAVITY lightweight releases are unchanged by this preview. Real device display, listening, and GRAVITY behavior remain unverified.

The home image is an original generated tavern image. The following SFXMint sounds are embedded as original MP3 data; playback is shortened and attenuated by the game, while the original audio bytes remain unmodified. SFXMint states its sounds are [CC0 1.0](https://sfxmint.com/license):

- Win: [feedback-level-up-71](https://sfxmint.com/dl/feedback-level-up-71.mp3)
- Loss: [retro-game-game-over-65](https://sfxmint.com/dl/retro-game-game-over-65.mp3)
- Coin: [retro-game-coin-52](https://sfxmint.com/dl/retro-game-coin-52.mp3)
- Sword: [impact-sword-11](https://sfxmint.com/dl/impact-sword-11.mp3)
- Ice: [magic-scifi-spell-61](https://sfxmint.com/dl/magic-scifi-spell-61.mp3)

Coin and ice individual information pages were unavailable to the earlier research tool, while their official files downloaded successfully. The site's general license covers its published sounds. The existing synthesizer supplies fallback cues if MP3 decoding is unavailable.
