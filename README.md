# どっちが勝つ

スマートフォンの配置、賭け中の操作、外れのコイン演出、攻撃表記と大型能力のピクセル演出を修正した版です。掴む能力3種は、承認された別の能力へ変更しました。HP・価格・攻撃対象属性、300種の選択ID、既存のキャラクター素材は維持しています。

## 修正内容

- トップの音量ボタンは絵の内側、開始ボタンの下。ゲーム中は右上です。
- 地形・ラウンド・金貨と数字・音量を横一段に整理。通常の地形説明は390pxでも欠けず、長い地形と金額は省略せず個別にスクロールできます。
- 賭け中もメニュー・エモート・情報を操作できます。次ラウンドで前のメニューを閉じ、同じ画面で開き直せます。参加者欄の横スクロールは維持しました。
- 外れで1枚の軌道判定により全12枚が消える問題を修正。数字を避けて連続して落下します。
- 全300種の数値欄を「攻撃」に統一。通常の画像読み込み案内は非表示にし、失敗時の再試行は残しました。
- 氷片、樹根、岩、炎、羽などのピクセル表現と既存の効果素材へ変更。水晶反射と端から撃つ光線の表示範囲も修正しました。
- ガントレットガードは拳の二連撃と衝撃波、ブルークラブジャイアントはハサミの一撃、シェルリッパーは前方防御と反撃へ変更。実際の接触時刻に攻撃フレームを合わせ、離れた敵への遠隔命中や中断後の残り攻撃を防ぎます。

[49種の能力一覧](BOSS_ABILITIES.md) ／ [対象を区別したバランス結果](BOSS_BALANCE.md)

## 検証

現在の仕様に対応した能力・共通試験189/189、実戦統合66/66が通過。置換3種の実戦25項目、描画88項目・実素材68フレーム、配置操作17項目、表記・読み込み・外れ演出も確認しています。試験は重複するため単純合算しません。

未変更の46種は92組の実戦と92組のリプレイで全状態・記録が一致。3種は156固定条件を変更前後で比較しました。過去の全49種2,572対戦を再実行したという意味ではありません。

古い試験を消して合格にはしていません。保存した173項目は134通過・39失敗。旧能力試験194項目は188通過・6失敗で、旧捕獲や古い表示時間などを期待する条件を個別に記録し、新仕様の対等な確認を追加しました。全49種の旧動作一致試験も281/300通過・19失敗として残しています。変更を承認された3種を「同じ」とは扱っていません。

[正確なソースと検証状態](CURRENT_PREVIEW_MANIFEST.json) ／ [検証範囲と失敗の対応](verification/ui-world-restore-20261107/VALIDATION.md) ／ [15組の描画比較](verification/ui-world-restore-20261107/visual/before-after-contact.png) ／ [新3種の実描画](verification/ui-world-restore-20261107/replacements/render-contact-sheet.png)

実ブラウザでは320～430pxの配置、通常版とGRAVITY用の上部余白、外れの実時間コイン移動、代表能力を確認しました。49種を各60ticks進めた確認は基本動作の確認であり、全条件の目視証明ではありません。新3種は左右反転と実接触、修正したQAリプレイを確認済みです。実機タッチ・iOS WebView、実GRAVITY SDKのスコア受付、実ネットワークのマルチ対戦は未確認です。

## 再現

```sh
node tools/boss-abilities/run-current.cjs /tmp/docchi-current-results
node tools/boss-abilities/run-canonical.cjs /tmp/docchi-canonical-results
```

前者は公開ソースを再構成し、旧試験の失敗を保存したうえで現行仕様の対応試験・復元項目を実行します。後者は保存した173項目を変更せず実行し、39件の失敗を非ゼロ終了で報告します。
