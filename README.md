# どっちが勝つ？ — v9 / 17兵種の予想バトル

独自コード・pixel artによる20戦の予想バトル。v9の実画面・実スマホ・実SDK通信・音の実機試聴は本パッケージ作成時点では未検証です。実画面確認は公開後に行う予定です。

## 操作
BETを選び、軍カードで陣営を選択し、「対戦開始」で確定します。未選択では開始できません。「配置を見る」は同じ戦場の静止プレビューへ切り替え、戻ってもBET・選択を保持します。プレビューで時間・乱数・財布は進みません。

戦闘中は兵情報、音のON/OFF、速度1×/2×、拡大・ドラッグ移動・全体表示を利用できます。⏸から再開/終了。ソロ結果は可視画面で3秒後に次の未入力予想へ進み、20戦目は止まります。3秒は独自UI設計です。未入力のまま自動で賭けることはありません。

## 勝者構成と進行（ユーザー指定）
- 実際に勝った軍の**戦闘開始時の兵種・人数**を、次戦の左に全員新品で引き継ぎます。
- 死者を除く処理、残HPの持ち越し、召喚・分裂した子の追加はありません。新しいID/token・全快HPで各能力も初期化します。
- 予想の正誤や財布に関係なく実winnerだけで決まります。元ラウンドの左右で精算を完了し、その後に次戦の左へ配置します。
- 引分/無効は両軍を新規生成。20戦後の新セッションでは構成・連勝をリセットします。
- 挑戦する右軍の目標costは `max(12+2*(round-1), ceil(左の開始cost*(1.04+min(連勝,4)*0.02))+2)`、上限160。種の候補と人数上限の中で、目標以下の最大実costを有限DPで詰めます。対空能力を必要とする構成条件を守ります。戦闘結果を見て再抽選することはありません。
- 右軍は第6〜11戦で2種、第12〜20戦で3種を必ず含みます。勝ち続ける左軍の構成は、このために勝手に増減させません。
- 初期人数上限は第1戦8/軍、第2〜5戦12/軍、第6〜11戦16/軍、第12〜16戦24/軍、第17戦以降32/軍。active+予約32/軍、総生成128/軍以下。大編成は半面内の8列配置、少数大型も半径に応じた行間です。

既存17兵種（spawn専用slimelet含む内部18）の個体能力・cost・物理solverはv8から不変です。costは完全較正済みの強さ保証ではありません。相性、配置、能力発動で安価側も勝てます。

## 経済（変更なし）
開始100 G、全20戦。無料的中+10 G、BET 0/10/25/50 G（残高以内）。的中はBET同額の利益も加算、はずれはBETだけ失います。引分は増減なし。0 Gでも無料予想で継続できます。スコアは純益=残高−100 G。Gは購入・換金できません。

## アート・音・表示
戦場は独自の480×538px苔土＋外縁石のPNG。内部に物理障害物は追加していません。spritesとCC0効果5点を維持し、旧grid/中央破線は除去しました。

音は外部サンプル/CDN不要の独自WebAudio合成。実ユーザー操作でのみunlockし、mute/非表示/停止/recordingを尊重します。発音数・node数には上限があり、音の失敗でゲームを止めません。生成・シミュレーション・財布は音から影響を受けません。

カード入場・選択チェック・開戦・結果の短いmotionは独自WAAPI実装です。入力/物理/精算を待たせず、非対応・低減設定・非表示では静止。数字は改変せず、演出だけを付けます。React/Three.js等への移行や外部アニメlibraryはありません。

## マルチ・ランキングの留保
部屋作成/参加は明示操作のみ。ホストの開始構成を共有し、guestはcanonical replayを再生して再simしません。次戦はホスト操作。途中参加の観戦・未入力timeoutは自動BETに変換しません。観戦受信遅延/ACK拒否で確定損益は取り消しません。

実GRAVITY/SDK通信と負の純益スコア受付は未検証。host信頼前提で暗号学的権威や秘匿保証なし。host移行・永続再接続は未実装。異なるversion混在は非対応です。ランキングは20戦終了後の明示操作で本人のsigned純益だけを1回送る設計、standaloneでは送りません。
