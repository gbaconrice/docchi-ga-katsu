## 今回の修正

- 戦数を大きくし、直下に予想・経過時間・速度を配置。参加者のアイコンと名前は賭け中・戦闘中とも横並びで、エモートは本人のアイコン右上に小さく表示します。
- 300種の特徴を短い用語に整理。左右の識別色を選択時の青・赤に揃え、詳細のキャラ名にも反映しました。戦闘開始の追加表示、重複した0G、結果のないログ、「不明」の代用表記を除きました。
- 引き分け後は両陣営を入れ替えます。勝者の編成は従来どおり継続。11戦目以降は条件に合う大型2～3種の編成も出現します。
- 同じゲーム内の同一対戦・似すぎた新規編成を避け、未登場の種類を優先。相手側と同種にならない条件は召喚・分裂する種類まで含みます。選出の少ない種類には価格・解禁条件を変えない補正を加えました。
- 最大60秒を維持し、既存の1×・2×・3×にダメージも連動。20秒で2倍、40秒で3倍です。延長、別の大型専用倍率、ダメージ倍率の追加表示はありません。
- 罠は接敵する場所に設置し、静止キャラの配置、罠の絵、カメラ追従を修正。死体の向きと位置は固定し、実際に蘇生した個体だけ再び動きます。
- 能力・状態・弾の描画を全系統点検し、欠けた表現や世界観に合わない簡素な描画を修正。元のキャラ画像・登録ID・価格は保持。「ゴブリン」は見た目に合わせて「シャドウクローラー」に改名しました。
- ホーム背景をアプリ全体へ適用。部屋の画面では音量ボタンと通常の接続状況表示を隠し、必要なエラーや操作は残しています。ゲーム内の音声操作とGRAVITY用余白は保持しました。
