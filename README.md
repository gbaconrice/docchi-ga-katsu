# どっちが勝つ

大型を中心とする49種類に、それぞれの個性が実際の戦闘へ反映される能力を追加した版です。価格、基礎HP、攻撃対象の属性、素材、300種類の選択IDは維持しています。既存の比較画面・財布・部屋の修正も引き継ぎます。

## 能力と調整

[49種類の実装一覧](BOSS_ABILITIES.md)に、各能力の発動条件、効果、上限と検証対象を記載しています。[バランス検証](BOSS_BALANCE.md)には、単体・混成・支援編成の実戦結果を区別して記載します。対戦相手や編成を固定した試験値であり、一般的な勝率や50％への調整目標を示すものではありません。

一律の大型ダメージ倍率に頼らず、範囲、多段、継続ダメージ、拘束時間、再使用待ち、召喚数を能力ごとに調整します。新しい拘束や成長が既存の解除・移動強化・回復・防御と共存することも検証対象です。

## 検証と再現

新しい試験187/187、実戦統合66/66、外部ローダー32＋7項目が通過しました。187件には能力ごとの58項目などの複合試験を含み、別々の合計として水増ししていません。49種・89場面のCanvas描画と、2,572回の対戦実行も同じソースで確認しています。

現在のソースの正確なハッシュと検証結果は[CURRENT_PREVIEW_MANIFEST.json](CURRENT_PREVIEW_MANIFEST.json)を参照してください。次のコマンドで公開ファイルからソースを再構成し、能力、互換性、実戦統合、外部ローダーの試験を実行できます。

```sh
node tools/boss-abilities/run-current.cjs /tmp/docchi-boss-results
```

旧版の正規試験も、新版のソースに対して元のまま再実行できます。このコマンドは24項目の失敗を失敗として報告し、終了コード1を返します。

```sh
node tools/boss-abilities/run-canonical.cjs /tmp/docchi-canonical-results
```

対戦検証の全2,572回を同じ編成・シードで再実行する手順は[対戦検証ツール](tools/boss-abilities/balance/README.md)を参照してください。ソースの復元・ハッシュ確認から行い、既存結果を使い回しません。

旧版の正規試験は元のまま保存しています。能力の差し替え、ソース識別値、リプレイ形式を旧仕様に固定する24項目は現在の版では失敗するため、173項目すべての合格とは表示しません。各失敗と新仕様の検証の対応は[旧試験との対応表](verification/boss-abilities-20261107/legacy-failure-traceability.md)に記載します。

実戦のstep()/draw()と実素材を使うCanvas2D描画確認に加え、実際のChromiumで通常の対戦・次ラウンド、49種の模擬編成、死亡時・反応型・成長・リプレイなどを確認しました。1180×757と500×757の画面で確認し、代表的な能力の見た目と入口の読み込みも調べています。[ブラウザ確認の範囲](verification/boss-abilities-20261107/browser/browser-qa.json)を参照してください。49種すべての効果を網羅的に目視確認したという意味ではありません。

物理タッチ、さらに狭い実機画面、実GRAVITY SDKでのスコア受付、実ネットワークのマルチ対戦は未確認です。公開後の配信確認も別途必要です。

## 入口と互換性

通常入口は[index.html](index.html)、GRAVITY組み込み用の外部ローダーは[GRAVITY_EXTERNAL_ENTRY.html](GRAVITY_EXTERNAL_ENTRY.html)です。[GRAVITY組み込み手順](GRAVITY_INTEGRATION.md)を参照してください。プロンプトの文字数制限とゲームHTMLのサイズは別です。

同じ部屋では全員が同じコンテンツ版を使う必要があります。旧版と新版の混在を検出して参加を拒否します。財布・スコアのデータ移行は不要です。

[能力確認用ページ](releases/boss-abilities-20261107/boss-preview.html)は明示した模擬編成を使う独立したQA入口です。通常入口には読み込みません。素材とライセンスは[ARTWORK](releases/boss-abilities-20261107/ARTWORK.md)とrelease内のlicensesを参照してください。
