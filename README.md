2026-11-07の修正版です。既存の地形表示・結果画面・画像音声・ユニットの価格と能力は保持しています。

## 今回の変更

- 高さ640px以下の画面では、比較カード内をスクロールできる配置にし、BETと開始ボタンを下段に配置。開始は48px、操作対象は44px以上を保持。画面全体の縦スクロールも予備経路として残しています。
- 同じゲーム中の対戦カードを記録し、未使用の組合せを優先。勝者の軍・位置を保持し、延長戦も履歴を引き継ぎます。新規ゲームでは初期化。合法候補を尽くした場合は使用回数・最終登場順の順に選びます。
- 戦闘ログの重複した終了理由・分かりにくい語句を整理。107種類の出来事、発生順、対象、詳細データは保持。比較人数の重複表示、ソロの不要な「あなた」表記も削除しました。
- マルチの10戦目以降は延長・終了の回答期限が30秒。未回答の参加者をホストが確定精算し、その参加者の動作中クライアントが自身のスコア送信を試みます。0G・安全な数値範囲外は従来通り送信しません。
- 全員終了すると同じ部屋のロビーへ戻ります。ホストの「もう一度遊ぶ」は参加者の確認後、新しいゲームID・財布・対戦履歴で再開。前のゲームの遅延通信やスコア重複を分離し、失敗した送信は再試行できます。

一般的な遠距離弱体化など、バランス数値の変更は含めていません。
