# どっちが勝つ？ — v11 quality candidate / 17兵種の予想バトル

独自コード・pixel artによる10戦の予想バトル。v10の実画面・実スマホ・実SDK通信・音の実機試聴は本パッケージ作成時点では未検証です。実画面確認は公開後に行う予定です。

## v11表示・音の追加
任意の☺から4つの短いリアクション。選ぶ/外を押すと閉じ、戦闘は止まりません。toolbar内に収まり戦場の常時面積は変えません。実eventに応じた独自合成の大技音4種を追加。詳細と留保はV11-QUALITY.md。実画面・実音・native通信は未検証です。

## 操作
BETを選び、軍カードで陣営を選択し、「対戦開始」で確定します。未選択では開始できません。「配置を見る」は同じ戦場の静止プレビューへ切り替え、戻ってもBET・選択を保持します。プレビューで時間・乱数・財布は進みません。

戦闘中は兵情報、音のON/OFF、速度1×/2×、拡大・ドラッグ移動・全体表示を利用できます。⏸から再開/終了。ソロ結果は可視画面で3秒後に次の未入力予想へ進み、10戦目は止まります。3秒は独自UI設計です。未入力のまま自動で賭けることはありません。

## 勝者構成と進行（ユーザー指定）
- 実際に勝った軍の**戦闘開始時の兵種・人数**を、次戦の左に全員新品で引き継ぎます。
- 死者を除く処理、残HPの持ち越し、召喚・分裂した子の追加はありません。新しいID/token・全快HPで各能力も初期化します。
- 予想の正誤や財布に関係なく実winnerだけで決まります。元ラウンドの左右で精算を完了し、その後に次戦の左へ配置します。
- 引分/無効は両軍を新規生成。10戦後の新セッションでは構成・連勝をリセットします。
- 10戦の進行stageは `1,3,5,7,9,11,13,15,17,20`。右軍は第4〜6戦で2種、第7〜10戦で3種を必ず含み、全17種が第7戦までに候補になります。勝者左軍は変更しません。
- 右軍目標costはstageの基礎予算と左開始cost・連勝の成長予算の大きい方（上限160）。2段階分の進行は成長率も累乗して圧縮します。較正候補では係数 `1.00+min(streak,4)*.005`、加算 `round(.5*advance)`。雷術師の生成見積costは5→7、治療比は最大35%（最低1体可）です。表示/個体のcost・能力値は変えません。有限DPで予算以下の最大実costを詰め、対空条件を守ります。勝敗を見た再抽選や予想依存の生成はありません。
- 初期上限は進行stageに応じ8/12/16/24/32体。active+予約32/軍、総生成128/軍以下。左軍は左、右軍は右から対面します。480×538の境界内で最大8行×4列、spritesは直立のままです。

17兵種の個体stats・cost・damage・capは変更なし。左右化に伴い召喚/潜行/同座標押し合いの方向とx鏡映丸めを更新しました。接戦率や完全較正済みの強さは保証しません。

## 長期戦と結果
20シミュレーション秒から最低2×、40秒から最低3×へ自動加速。手動倍率との最大値であり掛算しません。60シミュレーション秒で引分、増減0。固定tickの順序/勝敗は変えません。通常60秒分を約36.7可視秒で再生できますが低fpsでは1frame作業上限を優先します。

勝敗と精算差額は確定と同時に表示し、3秒の小さなprogress後に次の未入力予想へ進みます。10戦目は終了。soloのpause/非表示時間は加算しません。multiは共有host時計による同じ加速写像を使い、非表示guestは復帰時追いつきます（全員共有pauseではありません）。

## 経済（変更なし）
開始100 G、全10戦。無料的中+10 G、BET 0/10/25/50 G（残高以内）。的中はBET同額の利益も加算、はずれはBETだけ失います。引分は増減なし。0 Gでも無料予想で継続できます。スコアは純益=残高−100 G。Gは購入・換金できません。

## アート・音・表示
戦場は独自の480×538px苔土＋外縁石のPNG。内部に物理障害物は追加していません。spritesとCC0効果5点を維持し、旧grid/中央破線は除去しました。

音は外部サンプル/CDN不要の独自WebAudio合成。実ユーザー操作でのみunlockし、mute/非表示/停止/recordingを尊重します。発音数・node数には上限があり、音の失敗でゲームを止めません。生成・シミュレーション・財布は音から影響を受けません。

カード入場・選択チェック・開戦・結果の短いmotionは独自WAAPI実装です。入力/物理/精算を待たせず、非対応・低減設定・非表示では静止。数字は改変せず、演出だけを付けます。React/Three.js等への移行や外部アニメlibraryはありません。

## マルチ・ランキングの留保
部屋作成/参加は明示操作のみ。ホストの開始構成を共有し、guestはcanonical replayを再生して再simしません。次戦はホスト操作。途中参加の観戦・未入力timeoutは自動BETに変換しません。観戦受信遅延/ACK拒否で確定損益は取り消しません。

実GRAVITY/SDK通信と負の純益スコア受付は未検証。host信頼前提で暗号学的権威や秘匿保証なし。host移行・永続再接続は未実装。異なるversion混在は非対応です。ランキングは10戦終了後の明示操作で本人のsigned純益だけを1回送る設計、standaloneでは送りません。ローカルmodeは `GRAVITY_QUICK10_V1`、旧20戦protocolを拒否します。外部gameOver契約にmode欄は増やしていません。旧20戦とランキングを混ぜないため外部board分離設定の確認が必要です。今回実送信はしていません。
