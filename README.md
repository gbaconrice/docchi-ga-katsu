## 今回の修正

- ナンバーブラフの待機画面を参考に、参加者一覧とホストの開始操作があるルームロビーを用意。作成・参加・取消・退出を整理し、GRAVITY側の招待仕様は変更していません。
- 実プロフィールの読込、遅れたSDKの準備、読込失敗時の再試行、画像の代替表示を修正。ソロも同じ本人取得経路を使います。未取得時に架空の名前や画像は作りません。
- 賭け画面で開けなかったエモートと通信形式の不一致を修正。本人のアイコン右上に小さく表示し、メニューの外側タップで閉じます。
- 選択側のアイコンをカード左上に左から並べ、キャラ名やスクロールの長さに影響しない配置にしました。参加者名・勝利表示・戦闘ログの名前に追加されていた背景を取り除きました。
- 結果の折り畳み・見出し・繰り返しの金額説明を除き、的中者名を表示。通常の次戦待ちは30秒から8秒へ短縮。10戦後の継続・精算判断30秒と予想上限60秒は維持しました。
- 結果のない弾の消滅・終了通知などを非表示にし、実際のダメージ・回復・状態・防御結果は残しています。
- ホーム背景に実際のGIFを使用。元の酒場アートを残し、灯りの小さい範囲を動かします。読込失敗や低モーション設定では元PNGに戻ります。

以前の戦闘規則、300種・価格・選出、同種対戦回避、罠・カメラ・死体・能力描画の修正は保持しています。戦闘上限60秒、速度とダメージの1×・2×・3×連動も同じです。
