# どっちが勝つ？ 開発途中の確認用版（300種）

今回の追加調整では、所持・獲得ゴールドの数字を自然な共通書体にし、上部の操作ボタンが枠からはみ出して見える内側余白と戦数の表示バランスを修正しました。結果の「接戦」などの評価文は削除し、勝敗・金額・次へ・戦闘ログは保持しています。金額以外の書体、元の上部位置、44pxの操作範囲、盤面の位置、会計処理は維持しました。

この版では、全画面を覆う追加背景を外し、上部の文字・金貨・操作を整えました。戦闘前後も上部UIを維持し、名前・強調色・結果表示・ログを修正しています。マルチの通常戦は結果から30秒で次戦へ進み、10戦後の選択は手動です。大型46種の表示を拡大し、賭け画面だけ赤いボスマークを表示します。ホーム2ボタン、戦闘数値、財布・スコア処理、旧画像・音声は維持しています。識別情報は [CURRENT_PREVIEW_MANIFEST.json](CURRENT_PREVIEW_MANIFEST.json) を参照してください。154件のソース回帰と読み込み失敗からの復帰を確認しました。デスクトップChromeで320・375・390・430px、通常/GRAVITY余白、ソロ/マルチの16ケース64状態を確認しました。上下4px・右8pxのボタン内側余白、共通ゴールド数字、戦闘→結果の盤面位置維持を確認。通常ソロの実戦・結果評価文なし・履歴開閉・次戦も成功しました。実機iOS・実タッチ横スワイプ・実GRAVITY SDKとマルチ通信は未検証です。

`tools/external-release/test.cjs` と [EXTERNAL_RELEASE.md](EXTERNAL_RELEASE.md) は以前の固定リリース向けです。これらや以下の旧版検証記録を、現行版の合格結果として扱わないでください。

[GRAVITY内で遊ぶためのUI・SDK方針](GRAVITY_INTEGRATION.md)（実装済みの範囲と実機未検証事項）

ブラウザで確認できる開発途中のプレビュー向けパッケージです。GRAVITY提出はしていません。ゲームは常に無料です。

勝者は戦闘開始時の構成・人数を維持して全回復。挑戦者を入れ替えます。同一の種類・人数どうしの対戦は生成しません。
最初の10戦は残高の10%・25%・50%・75%・90%・全額から選択。端数は四捨五入し、残高があれば最低1G、残高を超えない。的中時の残高純増はBET額と同額、外れはBET額を減算、引分は増減なし。最初の10戦は残高0Gでも0Gで予想でき、的中で10G回復、外れ・引分は0Gのまま。10戦終了時以降に0Gなら予想終了です。
10戦終了後は毎戦「記録して終了」か全額ダブルアップ。的中で残高2倍、外れで0G終了、引分は残高維持です。ランキング用スコアは終了時の残高1つだけです。

旧版の PUBLIC_MANIFEST.json と VALIDATION.json は200種プレビュー当時の履歴であり、現在の300種版のハッシュや検証を保証しません。現行の外部入口と復元ソースのハッシュは CURRENT_PREVIEW_MANIFEST.json、旧版の検証手順と範囲は EXTERNAL_RELEASE.md に保存しています。AMOUNT_BACKGROUND_WORKTREE.md と VALIDATION_CURRENT.md は旧版の検証記録です。

以下は200種版の検証時点の記録です。200種は通常生成へ仮採用。新しい個体係数100種分は未学習で、実能力を表す共有特徴から比較します。失敗した再学習モデルは採用していません。12組の固定セッション検査では機能違反0ですが、150種比較では接戦数55→57、左勝利80→75、圧勝1→2。バランス改善完了とはいえません。

HP色は左青・右赤。能力比較、勝利時の実収益・厳密な2倍・終了残高の演出を収録。根拠のない「最後の一撃」演出は出しません。演出は物理・精算・時計を変えません。

地形の4%補正は仮設定。スマートフォン・音声実機・全種の密集描画、SDKのスコア上限やランキング受理は未確認です。外部ランキングに受理されたと偽表示しません。
