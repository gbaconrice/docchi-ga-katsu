## 今回の修正

- 指定画像に合わせ、左上に戦数、その下に地形を表示。長い効果は読みやすい短文と詳細表示で全文を確認できます。
- 所持金は26pxを維持して左寄せ。結果金額は指定の旧書体に復元しました。
- 結果画面でもメニューから終了、エモート、キャラ一覧を利用できます。
- 10戦後の終了ボタンは「ここで終了」「(ランキングに記録)」の2行。続行は「全額を賭けて挑戦」。賭けの選択肢が一つだけなら中央に表示します。
- ログの名前は陣営の青赤、本文とHPは中立色、実回復量は緑、勝者は対応する陣営色に整理しました。
- 自然な名称へ44件を改名。ID・能力・価格・画像、財布とスコアの仕様は保持しています。
