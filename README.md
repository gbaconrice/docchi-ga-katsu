# どっちが勝つ？ — 100種・開発途中の確認用版

`index.html` をそのまま開ける予想バトルです。ゲームは常に無料。Gはゲーム内通貨で、購入・換金できません。

## この版の内容
- 選択可能100種すべてに、出典確認済みの別原画を反映。内部の分裂子は100種に水増ししません。
- 体力・攻撃/支援・間隔・移動・間合いを同じ位置で比較し、短い特性を表示。
- HPバーは左チーム青・右チーム赤で固定。予想やHP割合では変色しません。
- 草原/浅瀬/横風の3戦場をrun開始前に決め、10戦と延長中は固定。
- 本人の実際の利益だけを獲得演出へ表示。標準絵文字のリアクション。
- 勝った軍の開始構成を次の左へ引き継ぎ、増援。延長は終了時に明示選択。

## まだ完成版ではありません
**500種完成・全体バランス調整・設定/UI/ルール/挙動の最終完成を示す版ではありません。** 実ブラウザ/モバイル/nativeでの見え方も継続確認中です。

このHTMLは旧選出モデルを継続。100種向け新モデルは別の未使用seed連戦で検証しており、ここには未採用です。浅瀬の地上移動−4%、横風の飛び道具の射撃開始間合い−4%は検証用候補値で、最終調整済みではありません。横風で実弾の速度・命中・飛距離は変更しません。色や名前から勝手な地形耐性は付けていません。

GRAVITYへの最終納品・登録ではありません。通常Webの開発確認用です。選択中/戦闘中の更新は避け、最新版を確認するときは新しいrunから始めてください。

## 操作
BET額を選び、左右の軍から予想を選んで対戦開始。「配置を見る」で同じ戦場を確認できます。最初は100 G・10戦。最初10戦は的中で10 GとBET同額の利益、はずれはBET分を失い、引分は0 G。11戦以降は的中の10 GをなくしBET損益のみです。残高0での延長はできません。

## 配布と権利
実行に必要な画像・音・コードはHTML内に埋込済みで、この配布に外部CDNや追加アセット取得は不要です。通常のローカル対戦は外部ネットワークを必要としません。

Behold Battleの画像素材は使っていません。採用したDuelyst由来のCC0キャラクター原画とSpritePilotのCC0効果は、自作とは称しません。原本のライセンス文は `licenses/` に無改変で保存し、元commit・元URL・PNG/plist SHA256・全source frame名は `provenance/` に記録しています。各原atlasの画素はそのままHTMLへ埋め込み、原典の能力を移植したとは称しません。制作側の全原本/clip/検証ソースarchiveも保持しています。この素材ライセンスをゲーム全体へ拡張した新たな全体LICENSEは付与していません。

画像生成による背景は本制作の素材です。ユーザー許可の通常縮小/圧縮で480×538へ最適化。標準絵文字は各OSのフォントで表示します。コード内には過去の自作フォールバック原画も保存していますが、現100種の表示では使用しません。
