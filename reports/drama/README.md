# 接戦・逆転の頻度と兵の散らばり（演出・自動カメラ設計用）

計測対象は main `50da1cd`（index.html の SHA-256 `9989ce84…f752`）。index.html は変更していません。300戦、Node v22、シードは固定していません。

- 計測：`node tools/balance/readability-sessions.cjs 75 tlN.json` を4並列で実行。0.25秒ごとに、両軍の残りHP・生存数・生存兵の外接矩形を記録します。
- 集計：`python3 tools/balance/drama.py reports/drama/tl?.json`（出力は result.txt）
- 優勢度：左右それぞれの「残りHP ÷ 最大HP」を比べた割合です。人数差のある軍どうしでも、開戦時は50:50になります。

## 結果（300戦）

| 項目 | 値 |
|---|---|
| 戦闘時間 | 中央値18.3秒、上位10%は30.5秒以上 |
| 勝者が一度でも劣勢（50%未満）になった | 66% |
| 戦闘の60%時点で、勝者が劣勢だった（終盤の逆転） | 11% |
| 最後の4分の1で、敗者がまだ35%以上残していた（接戦の決着） | 40% |
| 優勢の入れ替わり（45/55%を越えたもの） | 0回 88%、1回 11%、2回以上 1% |
| 勝者が40%未満まで追い込まれた | 3% |
| 勝敗が決まった時点（勝者が70%以上を保ち続けた最初の時点） | 戦闘全体の中央値80%の時点、50%より前は1% |
| 生存兵の外接矩形が盤面に占める割合（中央値） | 開戦0.92 → 25%時点0.51 → 50%時点0.35 → 75%時点0.25 → 決着0.13 |
| 生存兵が盤面の半分以内に収まる試合 | 25%時点48%、50%時点92%、75%時点96% |

## 演出設計への示唆

- 多くの試合は終盤まで勝敗が決まりません（決定は全体の80%の時点）。「接戦の決着」演出は条件次第で約4割の試合に出るので、条件を厳しくする必要があります（例：残りHPの差が小さく、生存数も少ない）。
- 優勢がはっきり入れ替わる試合は約12%と少数です。「大逆転」表示は珍しい演出として機能します。
- 生存兵全員を画面に入れたままでも、戦闘中盤には盤面の約3分の1の範囲に収まります。離れた射手を外さずに、約2.5倍まで寄れる計算です。
