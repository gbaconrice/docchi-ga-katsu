## 遠距離への対抗手段

遠距離の割合の差が0.25以上ある試合で、遠距離が多い側の勝率を、相手側の特徴ごとに分けました。勝率が50%前後まで下がれば、その特徴は対抗手段として機能しています。

| 条件 | 遠距離が多い側の勝率 |
|---|---|
| （全体） | 195/273 = **71%** (64–78%) |
| 相手に飛行がいる | 16/44 = 36% (21–59%) |
| 相手に飛行がいて、遠距離側の対空が少ない（<25%） | — |
| 相手に大型がいる（≥25%） | 61/72 = **85%** (75–92%) |
| 相手が範囲攻撃を持つ（≥25%） | 64/87 = **74%** (62–85%) |
| 相手の平均速度が遠距離側より10以上速い | 55/76 = **72%** (64–82%) |
| 相手の人数が1.5倍以上 | 32/64 = 50% (37–65%) |
| 相手の総HPが1.5倍以上 | 65/101 = **64%** (55–73%) |
| 遠距離側が遠距離だけ（100%） | 66/85 = **78%** (68–85%) |
| 遠距離側に前衛もいる（遠距離50%未満） | 76/106 = **72%** (60–82%) |

「相手に飛行がいて、遠距離側の対空が少ない」が0件（—）なのは、生成器が飛行の相手に対空を必ず含めるためと考えられます。
