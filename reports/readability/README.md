# 予想の「必勝法」調査（遠距離有利）

対象は main `50da1cd`、index.html の SHA-256 は `9989ce8461dc8c422beb22305396c7b0163f7bb9eb460a5a3c0f2bcfd479f752` です（その後の `1bd685a` は結果表示の変更のみ）。index.html は変更していません。

## 条件

- `tools/balance/readability-sessions.cjs` で、ひとりで遊ぶセッションを画面なしで実行しました。製品の戦闘ロジック・生成器・精算をそのまま使い、DOM だけをモックにしています。10戦ごとに新しいセッションを始めます。
- 4並列×150戦＝600戦（Node v22）。再開時のシードは Math.random を使っているため、シードによる再現はできません。同じ条件で再実行すれば同程度の値が出るはずです。
- 王者の判定：直前の勝者を王者とします。右が勝てば右に残り、左の勝利と引分では左に残ります。
- 「間合い」はユニット種の `reach`、遠距離は `reach >= 40` としました。

## 結果

| 予想のしかた | 的中率 |
|---|---|
| 1戦目に左 | 29/60 = 48% |
| 2戦目以降に王者 | 265/537 = 49% |
| 平均の間合いが長い側 | 397/586 = **68%**（1戦目は43/56 = 77%） |
| 遠距離の割合が大きい側 | 209/287 = **73%** |
| 遠距離だけ vs 近接だけで、遠距離側 | 45/54 = **83%** |
| HP合計が多い側（1戦目） | 19/60 = 32% |
| 人数が多い側 | 324/585 = 55% |

- 間合いが長い側と、もう一方の実コストの比は、中央値0.96・平均0.98でした。値段はほぼ同じなのに、遠距離側が勝っています。
- 実コスト比の対数と遠距離の割合の差でロジスティック回帰をすると、係数は2.67と2.22でした。遠距離だけの軍は値段の約2.3倍の強さという粗い推定になります（同一セッション内の依存と交絡があるため参考値です）。
- 王者の連勝数別：1勝目48%、2連勝47%、3連勝47%、4連勝以上67%（48戦）。
- 引分3、平均戦闘時間20.9秒、片側の最大人数64体。

## 解釈と注意

- PR #3 のコスト再設定は「1種類どうしの1対1」で測ったものでした。前衛が壁になり後衛が撃つ、という混成軍の相乗効果は反映されていません。
- 能力・地形・召喚の変更後には、同じスクリプトで再計測してください。
- 再現：`node tools/balance/readability-sessions.cjs 150 out.json` を並列で実行し、`python3 tools/balance/readability.py out*.json` で集計します。
- データ：`reports/readability/now1.json` 〜 `now4.json`（各試合の両軍ユニットの能力、コスト、連勝数、勝者）。
