# ボス49種 能力仕様と動作検証

対象ビルド SHA-256: `649a36f59f73219e0755d48a30735b60a8cc7d589ffa6442be0f5f0bc45a5ac7`

49種すべてに、HP・位置・状態・召喚などの固有の戦闘結果を確かめるテストを用意しました。58項目（各能力49項目＋共通・補助9項目）がすべて成功。状態異常・支援効果との相互作用34項目も同じビルドで成功しています。単なる演出発生や「何かにダメージが出た」だけを合格条件にはしていません。

## 読み方と共通の制限

- 60tick = 1秒。距離・半径は戦場内の座標単位。威力は最終的な防御・強化・弱体化によって変わります。
- 気絶・凍結・打ち上げは行動を止めます。束縛は移動だけを止めます。制御効果は次tickから始まり、効果終了後90tickの共通再拘束防止があります。
- 打ち上げは行動不能と上下演出による表現で、地上/空中の攻撃対象属性は切り替えません。
- 遅延する直接攻撃は使用者の死亡で中止します。設置済みの毒霧・溶岩・爪痕と付与済みの継続ダメージは、使用者が死亡しても各期限まで残ります。
- 同じ対象への無制限な多重命中、無限分裂、無限成長を避ける上限があります。召喚は配置余地とチーム/記録上限にも左右されます。
- 固有能力テストは実際の戦闘処理を使用し、多くは相手の通常攻撃を止めて効果を切り分けています。旋回・反復突進・薙ぎ払いと咆哮は通常の自動発動から確認しています。対戦バランスや全組合せの保証とは別です。

## 状態異常・通常ユニットとの連携

- ルーンエクソシストは、ソーンバック・トレント・シェルリッパーの束縛を解除できます。付与と同じtickには解除せず、解除tickの移動は止まったままで次tickから再開します。気絶・凍結・打ち上げ・炎上・毒・呪い・防御崩しはこの解除の対象外です。
- ボスの束縛と通常の束縛・スロウの耐性を相互に反映します。解除しても再拘束防止は消えません。束縛は突進・後退も止めますが、射程内の攻撃、外からの押し出し、重なり解消は妨げません。
- ランタンフェアリーの移動強化は地上のボスにも届きます。地上限定・最大2体・開始/終了時刻は通常の規則と同じです。
- 通常の回復役16種は、成長したボスの実際の最大HPを基準に対象を選び、元の最大HPを超えて回復できます。回復禁止、呪い、地形の補正は引き続き適用します。
- カースシンガーの攻撃遅延は、未発射の予備動作・再使用待ちと次の回転攻撃を21tick遅らせます。発射済みの連撃、弾、設置攻撃は遅らせません。
- イージスガードの誘導は、新しく狙いを決めるボスの最大2体に作用します。予備動作で確定した標的は変えず、後衛狙い・密集地点狙いの専用選択も維持します。
- 幽体化・地中にいる敵への状態異常は、ダメージ同様に拒否されます。味方の強化は受けられ、幽体化終了後は敵の状態異常も再び有効です。

## 修正して再検証した問題

- 盾破壊: 破壊した盾の同tickのスナップショットが残り、破壊攻撃まで軽減される問題を修正。101.25の攻撃が25.3125に減っていたケースで、盾破壊後は101.25になることを確認。
- 死体からの骸骨化: リッチの周囲から出現していた骸骨を、倒れた敵の位置付近から出現するよう修正。
- 旋回飛行: 目標点を追い切れず敵の手前で揺れるだけだった飛行を修正。実際に敵の反対側を回り、7.339rad旋回し、火雨8回を与えて終了することを確認。

## 支援役の追加調整

- ホーンドブレイバーは近接薙ぎ払いと全軍強化を独立させました。薙ぎ払いは138tickの命中間隔、咆哮は300tick間隔で180tickの1.35倍強化です。咆哮による直接ダメージはありません。
- リッチスクライブは同時3体を維持し、倒れた骸骨の補充を含めて累計6体まで召喚できます。出現待ちも同時上限に含め、同じ死体を再使用しないことを確認しています。
